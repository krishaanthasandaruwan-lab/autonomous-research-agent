# Autonomous AI Research Agent

An autonomous AI agent combining 6 models for research tasks.

## Features
- Code generation
- Web search
- Image analysis
- Audio transcription
- Multi-modal reasoning

## Setup
1. Clone this repo
2. Install: `pip install -r requirements.txt`
3. Set HF_TOKEN in .env
4. Run: `python autonomous_research_agent.py`

## Models Used
- Qwen2.5-7B-Instruct (planning)
- Qwen2.5-Coder-7B (code generation)
- LLaVA-1.5-7B (vision)
- Whisper-base (audio)
- SDXL (image generation)
- BLIP-2 (captioning)
